# fm18-erf — внешние отчёты

XML-выгрузки внешних отчётов. Часть проекта
[fm18](https://github.com/alex8angie/fm18) — там документация, ТЗ и описание
остальных четырёх репозиториев.

## Что здесь лежит

| Отчёт | Роль |
|---|---|
| `ЗаполненностьПитчей_УНФ_2025-12-10` | занятость питчей — сколько ёмкости цеха выбрано заказами |
| `СМ_ОбъемыПереносовСПитчаНаПитчУНФ` | объёмы переносов заказов с питча на питч |

Оба отчёта читают регистры механики питчей: ёмкость — регистр сведений
`СМ_РазмерПитча`, занятость — регистр накопления
`СМ_ВзаиморасчетыПоЗаказамПоставщикам`. Разбор механики целиком — в
[Питчи-общая-схема.md](https://github.com/alex8angie/fm18/blob/main/docs/Питчи-общая-схема.md).

## Правка выгрузки

Файлы — **UTF-8 с BOM и CRLF**, `.gitattributes` содержит `* -text`. Любая
конвертация переводов строк ломает обратную загрузку отчёта в 1С.
